# Bihar LET Practice Set — 3000 Core LIS Questions & Chronology

A distraction-free, mobile and desktop responsive web application built for rapid 4-day preparation and mastery of the **Bihar Library Eligibility Test (LET / SLET)** syllabus — focused strictly on **Core Library & Information Science (LIS)** and **LIS-related Computer/IT & Information Science**.

## Key Features

- **3,000 Verified Core LIS Questions** arranged strictly by **Priority (P1 Most Basic -> P5 Applied/Advanced)**:
  - **Set 1 (Q1–Q1500):** Main Core & Essential Must-Know Foundations (125 Qs per topic across 12 topics)
  - **Set 2 (Q1501–Q3000):** Deep Core Rules, Standards, Cataloguing/Classification Schemes, IT & Networks (125 Qs per topic)
- **Correct + All 3 Incorrect Options Explained**: Every single question includes detailed bilingual explanations for *why the correct option is right* AND *why each of the remaining 3 options is wrong*.
- **Year Chronology & Master Timeline**: Dedicated chronological timeline tab (`Before 1900` to `Present`) grouping landmark LIS acts, editions, organizations, and inventions by year for rapid memory recall.
- **2 Study Modes**:
  - `📖 Revise Mode`: Direct open answers & explanations for ultra-fast reading and 4-day cramming.
  - `🧠 Practice Mode`: Tap an option to test recall before revealing full explanations.
- **Distraction-Free Focus View (`🎯 Focus View`)**: Single-card centered workspace with Warm Sepia / Paper Light / Night Dark themes, adjustable font size, keyboard navigation (`←`, `→`, `Space`, `B`, `R`, `F`), mobile swipe support, and tri-mode language display (`हिन्दी + English`, `केवल हिन्दी`, `English Only`).
- **4-Day Study Plan & Progress Tracking**: Saves your `Revised` and `Bookmarked` progress locally in your browser (`localStorage`).
